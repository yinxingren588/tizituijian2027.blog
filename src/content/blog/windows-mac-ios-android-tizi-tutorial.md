## 二、Windows 电脑梯子配置教程（Clash Verge Rev）

**Clash Verge Rev** 是目前 Windows 平台最受欢迎的开源客户端，采用现代 Tauri 框架开发，启动迅速且界面友好。

### 配置四步法：
1. **下载与安装**：
   从官方 GitHub Release 页面下载最新的安装包（通常为 `.msi` 或 `.exe` 后缀），按提示完成安装并运行；
2. **复制梯子订阅链接**：
   登录您购买的梯子官网后台，找到“一键订阅”或“复制订阅链接（Clash格式）”；
3. **导入配置订阅**：
   打开 Clash Verge Rev，点击左侧菜单栏的 **“订阅 (Profiles)”**，在顶部输入框中粘贴刚刚复制的订阅链接，点击 **“导入 (Import)”**。导入成功后，选中该订阅配置；
4. **开启系统代理与分流**：
   * 点击左侧 **“代理 (Proxies)”** 页面，选择喜欢的国家或节点（建议选择延迟较低的香港、日本或新加坡）；
   * 点击左侧 **“设置 (Settings)”**，打开 **“系统代理 (System Proxy)”** 开关。此时右下角托盘图标亮起，即可畅享科学上网！

> **技巧提示**：推荐在代理模式中选择 **“规则 (Rule)”** 模式，这样访问百度、淘宝等国内网站会直连，访问 Google、YouTube、ChatGPT 时才会自动走梯子，既节省梯子流量又保证国内网速飞快。

## 三、macOS 苹果电脑梯子配置教程

对于苹果电脑用户，配置步骤与 Windows 几乎完全一致：

1. 下载并安装 **Clash Verge Rev for macOS**（根据芯片架构选择：M1/M2/M3/M4 芯片选择 `aarch64.dmg`，Intel 老款机型选择 `x64.dmg`）；
2. 首次打开时若提示未受信任，请在 macOS **“系统设置” -> “隐私与安全性”** 中点击“仍要打开”；
3. 粘贴梯子官网提供的订阅地址导入，勾选 **“系统代理”**；
4. 若需要让终端命令行或特定应用也走代理，可在设置中开启 **“Tun 虚拟网卡模式”**。

## 四、iOS 苹果手机/平板配置教程（Shadowrocket 小火箭）

在 iPhone 和 iPad 上，**Shadowrocket（俗称小火箭）** 是公认最好用、稳定性最高的翻墙梯子客户端。

### 关键步骤：
1. **准备海外 Apple ID**：
   由于政策限制，中国大陆 App Store 无法下载小火箭。您需要准备一个**美区或港区 Apple ID**（可在网络上自行注册或购买），登录 App Store 搜索 `Shadowrocket`（认准开发者为 `Pan modal`，图标为黑色火箭背景）；
2. **一键导入节点**：
   * 打开 Safari 浏览器登录梯子官网后台，点击 **“一键导入到 Shadowrocket”**，手机会自动弹出确认并直接写入所有节点；
   * 或者复制梯子提供的通用订阅链接，打开小火箭，右上角点击 **“+”号**，类型选择 **“Subscribe”**，在 URL 栏粘贴链接并保存，小火箭会自动拉取最新节点列表；
3. **启动连接**：
   在节点列表中点击选中一个节点，将全局路由模式设置为 **“配置 (Config)”**，打开最上方的连接开关，首次开启允许添加系统 VPN 描述文件即可成功翻墙。

## 五、Android 安卓手机梯子配置教程（Clash Meta for Android）

安卓平台开放自由，完全无需海外应用商店账号：

1. **获取客户端安装包**：
   直接在梯子后台或开源平台下载 `Clash Meta for Android` 的 `.apk` 安装包并完成安装；
2. **导入梯子订阅**：
   打开应用，点击 **“配置 (Profiles)” -> “新配置 (New)” -> “URL”**，粘贴梯子后台的订阅链接，右上角保存；
3. **选择节点并连接**：
   回到首页，点击 **“启动 (Start)”**，在弹出窗口中同意建立 VPN 连接；点击 **“代理”** 选项卡即可自由切换香港、台湾、美国等不同国家地区节点。

## 六、梯子常见报错自查与排障指南

在使用梯子客户端时，如果遇到“无法翻墙”或“全部节点超时”，请对照以下步骤自检：

1. **系统时间不准确（最常见原因）**：
   代理协议对时间同步要求极高。如果电脑或手机的时间与北京时间相差超过 60 秒，TLS 加密握手会全部失败。只需在系统设置中开启“自动与网络时间同步”即可秒级解决；
2. **订阅长期未更新**：
   梯子服务商为了对抗封锁，会不定期更换后端节点的解析域名。如果在客户端右键更新订阅，往往能立即刷新出可用节点；
3. **本地杀毒软件拦截**：
   Windows 上的 360 安全卫士、电脑管家有时会把代理内核的本地回环端口（如 7890 端口）拦截，建议将 Clash 目录添加到杀毒软件白名单；
4. **套餐到期或流量用尽**：
   登录梯子后台检查账户状态，确认账户是否欠费或月度流量已耗尽。
